# Rollout (breaking changes)

- RFC issue: blast radius (repos affected), codemod link, pilot cohort (1-2 repos, 2-4 weeks warning), rollback criterion (FP>5% or >2 rollbacks).
- Fleet waves: pilot → 25% → 100% with dates. Per-region progression for releases.
- Record outcome as ADR (`docs/audit.md` rule). Version MAJOR + CHANGELOG.
