# ADR 0001: Template

- Status: proposed
- Context: problem + constraints
- Options: A, B with tradeoffs, or `none — forced by <constraint>`
- Decision: choice + reason
- Consequences: what it costs, how it lands, what breaks if it is reversed
- Supersedes: omit unless this record replaces an earlier one; then name it
- Enforcement: the check or gate that enforces the decision, or `review`
