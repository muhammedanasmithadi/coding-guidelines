# 18 Accessibility

- Meet WCAG 2.2 AA. Source: https://www.w3.org/TR/WCAG22/
- Real `<label>`, real `<button>`, visible `:focus` (never `outline:none`), `aria-live` on async updates. No `<div onClick>`, no placeholder-as-label.
- Motion and input: honor `prefers-reduced-motion`, full keyboard navigation, and screen-reader announcements for async state.
- Check: `axe` 0 critical/serious in CI, Lighthouse a11y category, Storybook a11y addon in dev. Waivers: `docs/waivers.md` (temporal waiver with expiry + remediation date).

Sources: https://www.w3.org/TR/WCAG22/
