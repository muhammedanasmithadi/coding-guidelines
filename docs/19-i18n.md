# 19 Internationalization

- ICU messages with plurals. Store UTC (`TIMESTAMPTZ`). Render per-locale via CLDR. No hardcoded strings, dates, or naive local datetimes.
- Layout: ship pseudo-localization in CI and RTL screenshots; mirror layout for `dir="rtl"` locales.
- Check: ICU lint (no raw string literals in UI paths per team config), timezone test with DST edge, pseudo-localization/RTL snapshot tests. Waivers: `docs/waivers.md`.

Sources: ICU https://icu.unicode.org/, CLDR https://cldr.unicode.org/
