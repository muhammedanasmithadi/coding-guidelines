# A11y + I18n — Do vs Avoid

Sources: WCAG 2.2 https://www.w3.org/TR/WCAG22/, CLDR https://cldr.unicode.org/

## A11y (WCAG 2.2 AA)

Do:
```html
<label for="email">Email</label>
<input id="email" type="email" />
<button>Pay</button>
```

Avoid:
```html
<div onclick="pay()">Pay</div>
<input placeholder="Email" />
<!-- smell: no label, not keyboard-focusable, placeholder-as-label -->
```

Keep visible `:focus`, never `outline:none`. Announce async with `aria-live`. Gate: `axe` 0 critical/serious in CI.

## I18n

Do:
```ts
new Intl.DateTimeFormat(locale, { timeZone }).format(date);
intl.formatMessage("{n, plural, one {# item} other {# items}}", { n });
```

Avoid: `"Due " + d.toLocaleString()` hardcoded. Naive local datetimes double-bill across DST.

Store UTC (`TIMESTAMPTZ`), render CLDR per locale. No hardcoded strings or dates.
