# Postmortem template

- Title, date, severity, duration, owners.
- Summary (3 lines): impact, cause, fix.
- Timeline (UTC): detected, paged, mitigated, resolved.
- 5 whys: root cause, not symptom.
- Action items: owner + due date each. No ownerless items.
- Follow-up: flag/config change, test that would have caught it, audit link.
